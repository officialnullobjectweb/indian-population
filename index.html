How matching works

  • Loads public/data/india-states.geojson, public/data/india-districts.geojson (boundaries: DataMeet, CC BY 4.0, 2011 vintage), src/data/states.json + src/data/districts.json (640 districts, 118 Census columns, built by scripts/clean-data.js — local files only).
  • Names normalised: lower-cased, & → and, punctuation stripped; alias table fixes bangalore/bengaluru, gurgaon/gurugram, orissa/odisha, uttaranchal/uttarakhand and ~25 more vintage spellings.
  • Districts with no match show Data not available; every unmatched name is logged to the console for alias-table fixes.
  • Populations shown with Indian grouping (en-IN) plus lakhs / crores.

Source: Census 2011, Government of India.

Plain HTML/CSS/JS + local d3 (node_modules, no CDN). No API calls. Boundaries: DataMeet maps (CC BY 4.0).
